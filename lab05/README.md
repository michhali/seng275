# Lab 05

## Overview
This lab introduces **automated web testing** using Selenium and Java. The goal is to test web applications by simulating user interactions within a browser and verifying that the webpage behaves as expected.

Selenium works by controlling a web browser through a **WebDriver**, allowing tests to interact with elements such as buttons, text fields, and links just like a human user would. :contentReference[oaicite:0]{index=0}

The lab also includes **standards and compliance testing**, where automated tools are used to evaluate a webpage for accessibility, performance, and best practices.

## Technologies
- Java
- JUnit
- Selenium WebDriver
- Google Chrome / ChromeDriver
- Git / GitLab

## Implementation
The lab involved several testing tasks:

- **Selenium Setup**: Installed Selenium libraries and configured a WebDriver to control the browser.
- **Automated Web Tests**: Verified functionality on websites by interacting with elements such as search boxes and buttons.
- **UVic Website Tests**: Created tests that load the webpage, interact with the search feature, and verify expected results.
- **Standards Testing**: Used browser developer tools to run automated standards and accessibility checks.

## Running Tests
Tests can be executed in IntelliJ using the **JUnit runner**. Selenium will automatically launch a browser through the configured WebDriver and perform the automated interactions.
